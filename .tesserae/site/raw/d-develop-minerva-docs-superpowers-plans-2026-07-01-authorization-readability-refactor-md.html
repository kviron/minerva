    2026-07-01-authorization-readability-refactor.md

    D://develop//minerva//docs//superpowers//plans//2026-07-01-authorization-readability-refactor.md

    Authorization Readability Refactor Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Improve authorization type safety and readability while preserving every existing route, status, error code, and access decision.

    Architecture: Keep the Better Auth library assertion inside the Identity API adapter, expose a small browser-safe shared session view, cache successful server session resolution on the current H3 event, and centralize API access literals in an as const vocabulary. Pure policies remain separate from Nuxt/H3 effects.

    Tech Stack: TypeScript, Nuxt 4, H3/Nitro, Better Auth 1.6, Vitest, Playwright, Bun.

    • [ ] Step 3: Implement event-context caching

    Update server/modules/identity/session/require-session.ts:

    import type { H3Event } from 'h3'
import { IDENTITY_CODE } from '../../../../shared/identity/constants'
import { getAuth } from '../auth/get-auth'
import { IdentityError } from '../identity-error'

interface IdentitySessionContext {
  identitySession?: unknown
}

export function createRequireSession<Session>(
  getSession: (headers: Headers) => Promise<Session | null>,
) {
  return async function requireSession(event: H3Event): Promise<Session> {
    const context = event.context as typeof event.context & IdentitySessionContext
    if (context.identitySession !== undefined)
      return context.identitySession as Session

    const session = await getSession(event.headers)
    if (session === null)
      throw new IdentityError(IDENTITY_CODE.AUTH_REQUIRED)

    context.identitySession = session
    return session
  }
}

export const requireSession = createRequireSession(async headers =>
  await getAuth().api.getSession({ headers }) ?? null,
)

    Keep the cache local to event.context; do not introduce module-global session state or a complete actor object.
